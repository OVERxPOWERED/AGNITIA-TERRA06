# TERRA

**TERRA — Hybrid Renewable Forecasting, Trust & Dispatch Platform** for a virtual solar + wind plant in the Dewas wind belt near Indore, Madhya Pradesh.

## Status

under construction

## Quick start

`make setup && make demo-synthetic && make api` + `make web`
